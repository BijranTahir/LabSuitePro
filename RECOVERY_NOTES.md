# Recovery notes

The original Lab Suite Pro source was lost. Surviving artifacts included web/PWA builds and Windows packages. The public rebuild intentionally does **not** include any signing keystore or password.

The surviving application bundle should be retained privately as a historical/recovery artifact and should not be committed unless its licensing and provenance are appropriate.

Recovered calculator names should be validated against the legacy bundle before being represented as recovered functionality. Newly added calculators are marked as executable or reference based on this rebuild's implementation.
