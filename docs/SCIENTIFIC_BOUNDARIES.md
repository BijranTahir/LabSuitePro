# Scientific Measurement Boundary

Lab Suite Pro is a calculation, data-analysis, visualization, documentation and reproducibility workstation. It must not claim that a phone, browser or ordinary computer has performed a physical measurement that requires laboratory or analytical hardware.

## Three capability classes

### Local calculation
Can be performed directly in the application when the required inputs are supplied.

Examples: molarity, dilution, regression, qPCR ΔΔCt arithmetic, sequence statistics, Scherrer calculation from supplied XRD peak parameters.

### Instrument-data analysis
Requires a real measurement first, then the exported/raw data can be analysed locally.

Examples: XRD pattern analysis, Raman spectra, FTIR spectra, chromatograms, flow-cytometry tables, gel images, microscopy images.

### Physical measurement
Requires the appropriate laboratory/analytical instrument, sample preparation, calibration and safety controls.

Examples: acquiring an XRD pattern, collecting Raman spectra, operating SEM/TEM/AFM, measuring zeta potential, running DLS/BET/TGA/DSC/NMR/ICP-MS/HPLC/GC-MS, sequencing DNA, or acquiring flow-cytometry events.

## Required workflow

1. Define the scientific question and method.
2. Identify sample preparation, controls, calibration and safety requirements.
3. Acquire the measurement using the appropriate instrument.
4. Preserve the original/raw file.
5. Import or map the data into Lab Suite Pro.
6. Validate units, metadata, ranges, missingness and replicates.
7. Analyse and visualize.
8. Record assumptions, uncertainty and limitations.
9. Export results together with provenance and source data where appropriate.

Lab Suite Pro never fabricates an instrument trace, spectrum, diffraction pattern, micrograph, chromatogram, sequencing run or measurement value merely because the user has selected a method.
