# Lab Suite Pro v5 Implementation Matrix

## Implemented local engines
- Scientific calculator, units, dimensional conversion
- Descriptive statistics, bootstrap, regression, polynomial fitting
- Numerical integration/root finding
- Sequence GC, reverse complement, translation, primer Tm
- Chemistry molar mass, Beer-Lambert, Arrhenius
- Biochemistry Michaelis-Menten/Hill
- qPCR ΔCt/ΔΔCt, LOD/LOQ
- imaging geometry metrics
- XRD Bragg/Scherrer calculations
- ecology diversity indices
- AI metrics/scaling/similarity
- engineering mechanics/electrical basics
- astronomy/physics reference calculations
- local CSV data workspace and SVG plotting
- project history/provenance log

## Framework modules
Specialist modules whose algorithms require larger dedicated implementations are explicitly marked `framework`; they do not fabricate results.

## Scientific integrity
Every result is a computed estimate/calculation. Instrument measurements and clinical diagnoses are not claimed. Advanced methods should expose assumptions, units, validation and references before production use.
